# NOVA WING — Star Assault

Jogo de nave estilo *rail shooter* (inspirado em Star Fox / R-Type), em 3D de polígonos, rodando 100% no navegador a partir de um único arquivo HTML — sem servidor, sem build, sem dependências.

Você pilota a **Bia**, gata preta líder do esquadrão **Five Cats**, numa jornada que começa nos céus da Terra e segue até o espaço profundo para enfrentar o vilão **Marvin** e sua nave-mãe.

## Como rodar localmente

É um arquivo único. Basta abrir o `index.html` no navegador (duplo clique) — funciona em desktop e celular.

## Controles

| Ação | Teclado | Toque (celular) |
|------|---------|-----------------|
| Mover | Setas / WASD | Joystick virtual |
| Atirar (segurar carrega plasma) | Espaço | Botão FOGO |
| Turbo | Shift | Botão TURBO |
| Barrel roll (toque) / virar de lado (segurar) | Z | Botão ROLL |
| Bomba | X | Botão 💣 |
| Granada cósmica | C | Botão GRAN |
| Pausar | P | Botão ⏸ |
| Música on/off | — | Botão ♪ |

## Características

- 10 fases com progressão Terra → espaço, cada uma com cenário e música próprios
- Inimigos variados (caças, drones, robôs, alienígenas, cruzadores) com pontos fracos
- Chefes grandes que alternam entre nave, monstro e ciborgue
- Anéis de benefício (verde = vida, azul = melhoria de arma)
- Sistema de upgrades, patentes e diálogos entre Bia e Marvin
- HUD com escudo, turbo, potência de arma e velocímetro
- Responsivo: adapta-se a qualquer tamanho de tela

## Tecnologia

HTML5 Canvas 2D puro com engine de polígonos 3D própria, áudio via WebAudio. Tudo original (código, arte e trilha sonora).
